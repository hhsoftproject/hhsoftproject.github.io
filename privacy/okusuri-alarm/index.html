プライバシーポリシー — おくすりアラーム

最終更新日: 2026年10月1日

このアプリは、おくすりを飲む時間をお知らせし、飲んだ記録を残すためのものです。 記録はすべて、お使いのスマートフォンの中だけに保存されます。 わたしたちはサーバーを持っておらず、あなたの記録を受け取ることも、見ることもできません。

1. アプリに保存されるもの

次のものが、スマートフォンの中のデータベースに保存されます。

  • つかう人の「よび名」（母・父・わたし など、あなたが決めた呼び方）
  • おくすりの名前・量・飲む時刻・曜日
  • 飲んだ記録（日付と時刻）
  • 血圧・脈拍の記録
  • 日付につけたメモ
  • 見え方の設定（文字の大きさ・色の濃さ）、アプリロックの入切

これらが端末の外に出ることはありません。 ただし、次の2つはあなたの操作によって外に出ます。

  • 書き出し：「記録を書き出す」を押して、あなたが選んだ保存先にCSVまたはPDFを保存したとき
  • バックアップ：Androidの自動バックアップ機能（下の7をご覧ください）

2. 許可（権限）について

アプリが使う許可と、その理由です。

許可なぜ必要か
通知おくすりの時間をお知らせするため
正確なアラーム食前・就寝前は時刻そのものが大切なため。数十分ずれるお知らせは、正しいお知らせではありません
再起動時の起動スマートフォンを再起動したあとも、お知らせを設定し直すため
バイブレーションお知らせのため
電池の最適化の除外（任意）眠っているあいだもお知らせを遅らせないため。許可しなくても使えます
画面いっぱいのお知らせ（任意）設定でオンにしたときだけ使います。既定ではオフです
生体認証・指紋アプリロックのため。指紋や顔のデータをアプリが受け取ることはありません — 確認はAndroidが行い、アプリは「合っていたかどうか」だけを受け取ります
インターネット・ネットワーク状態広告の表示と購入の確認のため
広告ID下の3をご覧ください
課金下の6をご覧ください

カメラ・位置情報・連絡先・ファイルへのアクセス許可は使いません。

3. 広告について

アプリ内に広告を表示します（Google AdMob）。広告の配信のために、 Googleがあなたの端末の広告IDなどを利用することがあります。

  • ヨーロッパ経済領域（EEA）・英国・スイスの方には、最初の起動時に同意の画面を表示します（Google User Messaging Platform）。
  • 広告IDは、Androidの設定からいつでもリセットまたは削除できます。
  • Googleのプライバシーポリシー: https://policies.google.com/privacy
  • 広告のパートナー一覧: https://support.google.com/admob/answer/9012903

広告をなくす：1回のお支払いで広告を消すことができます（下の6）。

4. 利用状況の計測について

アプリにはGoogleのFirebase Analyticsが組み込まれています。 これにより、アプリの起動回数や画面の表示といった使われ方の記録と、 端末の識別子がGoogleに送られることがあります。

おくすりの名前・飲んだ記録・血圧の数値が送られることはありません。 これらはアプリの中のデータベースにのみ保存され、計測には使われていません。

  • Firebaseのプライバシー情報: https://firebase.google.com/support/privacy

5. 記録の書き出しについて

「記録を書き出す」を押すと、直近90日ぶんの記録をCSVまたはPDFにして、 あなたが選んだ保存先に保存します。保存先を選ぶ画面はAndroidのもので、 アプリが勝手に場所を決めることはありません。

書き出したファイルはあなたの持ち物です。どこに送るか、誰に見せるかは、あなたが決めます。 一度書き出したファイルには、このアプリのロックはかかりません。

6. 購入について

「広告なしで使う」は、Google Playの課金を使った1回かぎりのお支払いです。月々の支払いはありません。 お支払いの処理はすべてGoogle Playが行い、カード番号などの支払い情報をアプリが受け取ることはありません。 アプリが知るのは「購入済みかどうか」だけです。

同じGoogleアカウントであれば、機種を変えても広告は出ません。

7. バックアップについて

Androidの自動バックアップにより、アプリのデータがあなたのGoogleアカウントに バックアップされることがあります。これはAndroidの機能で、 Androidの設定からいつでもオフにできます（設定 → Google → バックアップ）。

8. アプリロックについて

「アプリにロックをかける」をオンにすると、アプリを開くときに 指紋または画面ロックで確認します。

このロックがかからないものをはっきりさせておきます。

  • お知らせに表示される文字（おくすりの名前）
  • 書き出したCSV・PDFファイル
  • Androidのバックアップ

「ロックをかけたから安全」と読まれるほうが危険なため、ここに書いています。

9. お子さまについて

このアプリは13歳未満の方を対象としていません。 13歳未満の方の情報を意図的に集めることはありません。

10. 健康に関する情報について

おくすりの記録と血圧の記録は、健康に関する情報です。 これらは端末の中だけに保存され、わたしたちのサーバーに送られることはありません （わたしたちはサーバーを持っていません）。 広告や計測のために使われることもありません。

このアプリは医療機器ではなく、診断を行うものでもありません。 画面や書き出した紙に表示される数値は記録であって、診断ではありません。

11. 記録の削除について

アプリ内でおくすりや記録を削除できます。 すべてを消したいときは、Androidの設定からアプリのデータを削除してください （設定 → アプリ → おくすりアラーム → ストレージ → データを削除）。 わたしたちの側に控えはないため、削除すると元に戻せません。
